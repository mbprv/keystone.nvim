*keystone-quickfix*    Shows quickfix and location lists in a floating window

==============================================================================
Table of Contents                         *keystone-quickfix-table-of-contents*

1. Configuration                            |keystone-quickfix-configuration|
2. Keys                                                  |keystone-quickfix-keys|
Shows the quickfix or location list window as a bottom-anchored float. The
native split is closed as the float opens, and the real quickfix buffer is
reused, so `:cnext`, `:lnext` and the `qf` ftplugin behave as they do in a
split.

The float is drawn with the editor's `Normal` highlight, rounded border, and
the same bottom-bar geometry as lspnav.nvim, so it reads as part of the editor
rather than a popup.

Every quickfix and location list window is adopted as it opens, including the
ones opened by `:make`, `:copen`/`:lopen` and `:cwindow`.


==============================================================================
1. Configuration                            *keystone-quickfix-configuration*

>lua
    require("keystone").setup({ quickfix = true })
<

>lua
    require("keystone").setup({
      quickfix = {
        height = 0.3,          -- float height as a fraction of the editor area
        width  = 1.0,          -- float width as a fraction of the editor columns
        border = "rounded",    -- nvim_open_win() border, or "none"
        title  = true,         -- show the list title in the border
        keys   = {
          close = "<Esc>",     -- close the float
          split = "<C-q>",     -- replace the float with the native split
        },
      },
    })
<

Sizing is measured against the editor grid, so the command line stays visible
below the float. The keys are buffer-local and exist only while the float is
open.


==============================================================================
2. Keys                                              *keystone-quickfix-keys*

  Key       Action
  -------- ---------------------------------------------------------------
  <Esc>     Close the float; focus returns to the window below it
  <C-q>     Close the float and reopen the quickfix or location list split

`<C-q>` runs the native command under `:noautocmd`, so the reopened split stays
a split. Running `:copen` or `:lopen` again while the float is open refreshes
the list and discards the extra split.
